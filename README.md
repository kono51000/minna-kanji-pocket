# みんなの漢字ポケット

`index.html` をブラウザで開くと練習できます。サーバー、アカウント、ビルド作業は不要です。

- 初級IのUnit 1〜20を収録しています。ユニット分けの参考は[日本語NETの漢字一覧](https://nihongokyoshi-net.com/minnano-nihongo-kanji/)です。
- 漢字単体、ランダム最大10問、ユニット別のことばの練習に対応します。ことばの問題はこのアプリ用に選んでいます。
- お手本は5秒表示されます。判定は文字の形の比較で、書き順は判定しません。
- 修了証の平均一致度は合格した各文字の一致度の平均です。修了証はPNGで保存できます。
- 名前と練習結果はブラウザ内で処理します。
